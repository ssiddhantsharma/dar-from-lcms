# Second benchmark: cytotoxic ADCs (PRIDE PXD063887)

A second, independent public dataset, complementing the van der Zon immunoconjugates (`README.md`).
Where van der Zon is the quantitative CAR benchmark, this one is a **mass-assignment** benchmark on
three commercial cytotoxic ADCs of two conjugation chemistries.

## Dataset

Fiala, Schuster & Heck, *J. Am. Soc. Mass Spectrom.* 2025, 36, 1395-1403,
doi:10.1021/jasms.5c00109 (CC-BY). Raw data: ProteomeXchange **PXD063887** (Thermo `.raw`).

- Brentuximab vedotin (cysteine, MMAE)
- Enfortumab vedotin (cysteine, MMAE)
- Trastuzumab emtansine / T-DM1 (lysine, DM1-SMCC), deglycosylated

Native variable-temperature ESI (static nanospray, a temperature ramp 30->100 C), so there is no LC:
the scan-time axis is the temperature ramp, mapped to temperature via the deposited `_rampdata.txt`
logs. The paper's ground truth is DAR-resolved **thermal stability (T-half per drug load)**, Tables
S3 (cysteine) and S4 (lysine), not an average DAR; label/literature avDAR (BV ~4, EV ~3.8, T-DM1
~3.5) is the weaker comparison used below.

## Result: low-temperature DAR assignment (this tool)

Deconvolved with ThermoRawFileParser (converted under QEMU-JIT, ~80 s each) + UniDec, over an early
(~37 C) scan window where the ADC is intact:

| ADC | this tool avDAR | label | chemistry reproduced |
|---|---|---|---|
| Brentuximab vedotin | 3.66 | ~4.0 | even-DAR (cys): DAR4 0.40, DAR2 0.26, DAR6 0.18, odds ~0 |
| Enfortumab vedotin | 3.25 | ~3.8 | even-DAR (cys): DAR4 0.43, DAR2 0.38, odds ~0 |
| Trastuzumab emtansine | 2.70 | ~3.5 | all-loads (lys): DAR0-6, DAR2 0.43, DAR4 0.31 |

All three reproduce the correct conjugation signature (even-only for the cysteine ADCs, a full
DAR0-6 ladder for the lysine ADC) and read ~10-23% low, the same low-DAR-overweight direction seen
on van der Zon. See `benchmark_parity.png` for the combined parity plot across both datasets
(11 points, overall MAE 0.40).

Anchors were read from the data (drug-load ladder spacing = drug-linker mass; base = the CAR0 apex),
not from the paper, which does not tabulate them: BV base 145232 / step 1314; EV base 143750 / step
1314; T-DM1 base 145167 / step 957.5.

Reproduce (BV shown; EV/TD swap BASE_MASS/MOD_MASS and DAR_MAX_N=6 for TD):

```
MODE=native MASSBINS=1.0 MASS_LB=141000 MASS_UB=310000 \
  MZ_LO=4000 MZ_HI=7000 Z_LO=20 Z_HI=55 SATELLITES=0 DAR_MAX_N=8 \
  BASE_MASS=145232 MOD_MASS=1314 TMIN=5.5 TMAX=6.5 ./dar ./raw
```

## Lesson (recorded): open the mass range so multimers park separately

The first EV/TD attempts failed because `MASS_UB` was capped below the dimer (~2x monomer); UniDec
then force-fit the dimer's charge states into the monomer mass range and the ladder came out garbage.
Setting `MASS_UB` high (310 kDa) lets multimers deconvolve to their own mass and the monomer DAR
ladder reads cleanly. EV is dimer-heavy at 2 uM (the dimer is the global-max species), but its
monomer bands are unaffected because they are anchored in the 143-158 kDa region.

## Thermal-stability (T-half) adversarial test: reproducible, not run to completion

The paper's quantitative target is the melting midpoint per drug load (Tables S3/S4):

| ADC | DAR | published T-half (C) |
|---|---|---|
| Brentuximab vedotin | 4 / 6 / 8 | 55.5 / 51.0 / 47.1 |
| Enfortumab vedotin | 4 / 6 / 8 | 51.6 / 49.8 / 47.2 |
| T-DM1 | 0 .. 6 | 68.1 / 66.4 / 65.6 / 65.0 / 64.0 / 63.3 / 60.9 |

Higher DAR melts first (lower T-half). The reproduction is a temperature-resolved sweep: map each
scan to temperature via `_rampdata.txt` (ramp start 30 C, 2 C/min), deconvolve in temperature bins
with the anchors above, track each state's `dar_state_areas` vs temperature, and take T-half as the
50% crossing. This tool's `NO_CACHE`/window controls make that a scripted loop over `TMIN`/`TMAX`
bins. It was set up (28 bins across the three ramps) but not run to completion in this session; it is
left as a documented, reproducible test rather than reported with partial data.

## Takeaway

On three commercial ADCs the tool assigns the drug-load ladder correctly for both cysteine
(even-DAR) and lysine (full-ladder) conjugation, from raw vendor files, with avDAR within ~0.5 of the
label. Combined with van der Zon, the tool is validated across two antibodies-plus-ADCs, two
conjugate classes (chelator and cytotoxic), and multiple chemistries. It remains an approximation
that reads slightly low, not a bit-exact method.
